1. Request Gateway

FastAPI app on port 50123: routes, auth, admin/config-reload endpoints, and app-wide state (config, caches, Ollama health flag). Delegates all per-request orchestration to Completion Service.

app/request_gateway.py
🧬

Completion Service

Orchestrates a single request end-to-end: routing decision, exact/semantic cache lookup, repo/websearch enrichment, local streaming with cloud fallback, and metrics. Owns no state — receives it from the gateway per request.

app/completion_service.py
🧠

Classifies incoming queries for keyword complexity, prompt length, freshness search intent, and exfiltration policy matches.

app/intent_detection.py

Backbone & Subsystems

Services that support execution: Exact-match LRU/Redis cache (SHA-256), Semantic Cache (cosine similarity via nomic-embed-text), FinOps observability, and Ollama model health monitoring.

app/context_cache.py, semantic_cache.py, observability.py

PostgreSQL Persistence

System-of-record for the gateway: metrics, api_tokens, admins, and ui_sessions tables via an asyncpg connection pool. Metrics fall back to data/metrics.jsonl if the DB insert fails.

app/db.py — docker-compose service "db"
🌐

SearXNG Web Search

Self-hosted metasearch engine, called by the gateway's websearch route for freshness queries. Runs as a sibling container (http://searxng:8080); results are injected as context and the request falls through to local dispatch — no cloud call needed for a lookup.

app/websearch.py — docker-compose service "searxng"

Context Intelligence (v3.0)

Four new modules shipped in v3.0 — integrated natively with zero additional runtime dependencies. All degrade gracefully.

📐

BM25 Corpus Scorer

Replaces the keyword counter in repo context retrieval with IDF-weighted scoring. Rare identifiers earn high weight; common tokens (def, import) approach zero. Includes TF saturation, length normalisation, long-token bonus (+0.3), and path boost (+0.15).

app/bm25.py — SDD 4 +30%, SDD 6 +60%
🗜️

ASGI Compression Middleware

Intercepts all POST requests before route handlers. Applies three transforms: rolling window (keeps system + first + last N turns), SmartCrush (collapses large JSON arrays), and code-block dedup (MD5 back-references). Stats in response headers.

app/compression.py — SDD 1 +15%, SDD 3 +30%
✂️

Output Shaper

Reduces cloud response verbosity by appending byte-stable verbosity instructions to the system prompt before every cloud dispatch. Turn classifier detects NEW_USER_ASK (level 2), MECHANICAL_CONTINUATION (level 3), or ERROR_CONTINUATION (level 1). Works for all providers: Gemini, OpenAI, and Cursor.

app/output_shaper.py — SDD 7 +10%, Response Optimizer +20%
🔍

Semantic Cache

Second cache layer (after SHA-256 exact cache, before inference). Embeds the raw user query with nomic-embed-text:latest via Ollama and returns a stored response if cosine similarity ≥ 0.92. Disables itself after 3 consecutive Ollama failures. ~5–20 ms lookup.

app/semantic_cache.py — SDD 6 +60%

Model Routing Stack & Heuristics

Current 3-tier local model stack and cloud escalation routing configurations.

⚡ Local Fast

qwen2.5-coder:7b

Fast & Private
💻 Local Main

qwen3.5:9b

Primary model for standard code-writing tasks and medium-complexity queries (800–2000 chars).

Main Coding Engine
🤖 Local Mid

qwen2.5-coder:7b

Serves highly complex prompts and refactor requests that do not require real-time web context. Set via ollama.midModel — same model as Fast in the current config, swap independently via Admin > Config.

Reasoning Fallback
☁️ Cloud Escalation
